Setting & Privacy

Admin उपकरणका स्थानीय प्रदर्शन प्राथमिकता। यी सेटिङले server policy परिवर्तन गर्दैनन्।

गोपनीयता नियम: पासवर्ड, OTP, service-role key वा संवेदनशील ग्राहक विवरण localStorage मा नराख्नुहोस्। सार्वजनिक HTML भित्र secret key नराख्नुहोस्।

Audit & Backup

यो browser session का सीमित event मात्र; server-side audit log होइन।

वास्तविक audit log database मा insert-only नीति र RLS सहित server-side लागू गर्नुपर्छ।

सहायता तथा स्थापना

GitHub Pages मा यो पृष्ठ static frontend का रूपमा चल्छ।

आवश्यक database contract

public.admin_users table मा कम्तीमा user_id uuid, role text, is_active boolean राख्नुहोस्। Admin ले आफ्नै row पढ्न मिल्ने SELECT RLS policy चाहिन्छ। Admin row थप्ने/हटाउने अनुमति public users लाई नदिनुहोस्।

स्थापना

  1. यो फाइल admin/index.html रूपमा repository मा राख्नुहोस्।
  2. GitHub Pages deploy भएपछि /Mero-Sewa/admin/ खोल्नुहोस्।
  3. Supabase Authentication मा Admin account बनाउनुहोस्।
  4. Trusted SQL editor बाट मात्र उक्त user को admin_users row बनाउनुहोस् र RLS जाँच्नुहोस्।

यो पृष्ठले मूल index.html, GitHub repository वा Supabase schema आफैँ परिवर्तन गर्दैन।
